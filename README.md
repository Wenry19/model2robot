# Detectdoor: From Custom CNN Training to TensorRT Deployment

**Detectdoor** is an end-to-end computer vision project that demonstrates the complete lifecycle of a deep learning model: from designing and training a custom convolutional neural network (CNN) in PyTorch to exporting it to ONNX and deploying an optimized TensorRT engine for high-performance inference.
